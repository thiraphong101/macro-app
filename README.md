# Macro App

เว็บแอปบันทึกแคลอรีและโปรตีนภาษาไทยสำหรับ deploy บน GitHub Pages

## ใช้งานบน GitHub Pages

1. อัปโหลด `calorie.html` และ `food-db.json` ขึ้น repository เดียวกัน
2. ไปที่ **Settings > Pages** แล้วเลือก source เป็น branch ที่ต้องการและโฟลเดอร์ `/ (root)`
3. เปิด URL ที่ GitHub Pages สร้างให้ โดยใช้ชื่อไฟล์ `calorie.html`

`food-db.json` เป็นเพียงรายการเมนูอาหารสำหรับค้นหา ส่วนข้อมูลที่ผู้ใช้เลือกกินในแต่ละมื้อจะถูกบันทึกอัตโนมัติใน browser

## การจัดเก็บข้อมูล

ประวัติอาหารทั้งหมดแยกตามวันที่และเป้าหมายส่วนตัวเก็บใน `localStorage` ของ browser เมื่อเปิดแอปครั้งถัดไปบน browser และอุปกรณ์เดิม ข้อมูลที่บันทึกไว้จะถูกโหลดกลับมาอัตโนมัติ

ข้อมูลนี้ไม่ถูกเขียนกลับไปที่ GitHub หากต้องการเปิดดูข้อมูลชุดเดียวกันจากหลายอุปกรณ์ หรือต้องการให้ผู้ใช้หลายคนบันทึกร่วมกัน ต้องเพิ่ม backend หรือฐานข้อมูลภายนอก เช่น Supabase/Firebase
